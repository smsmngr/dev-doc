SmsManager JSON API v2 vám umožňuje odesílat SMS zprávy na jakékoli telefonní číslo po celém světě jediným HTTP požadavkem. Tento průvodce vás provede vším od minimálního jednořádkového kódu po plně nakonfigurovanou zprávu s vlastním odesílatelem, podporou Unicode a definicí callback adresy.

## Předpoklady

- Aktivní účet SmsManager
- API klíč z [app.smsmanager.com](https://app.smsmanager.com)
- Základní URL: `https://api.smsmngr.com/v2`
- Hlavička autentizace: `x-api-key: YOUR_API_KEY`

---

<Steps>
  <Step title="Odešlete svoji první SMS">
    Nejjednodušší požadavek potřebuje jen dvě pole: `body` (text zprávy) a `to` (pole příjemců). Každý příjemce je objekt s polem `phone_number` v mezinárodním formátu bez úvodního `+`.

    ```bash cURL
    curl -X POST https://api.smsmngr.com/v2/message \
      -H "x-api-key: YOUR_API_KEY" \
      -H "Content-Type: application/json" \
      -d '{
        "body": "Ahoj od SmsManageru!",
        "to": [{"phone_number": "420777123456"}]
      }'
    ```

    ```json Tělo požadavku
    {
      "body": "Ahoj od SmsManageru!",
      "to": [{"phone_number": "420777123456"}]
    }
    ```

    Úspěšná odpověď vrací `request_id` a pole přijatých příjemců, každý s jedinečným `message_id`, kterým můžete sledovat doručení.
  </Step>
  <Step title="Nastavte jméno odesílatele">
    Pole `flow` slouží k nakonfigurování voleb specifických pro kanál. Pro SMS přidejte objekt `sms` uvnitř kroku flow s polem `sender`. Alfanumerická jména odesílatele mohou mít až 11 znaků. Pokud používáte jako odesílatele virtuální číslo, vynechte úvodní `+`.

    ```json Tělo požadavku
    {
      "body": "Vaše objednávka byla odeslána!",
      "to": [{"phone_number": "420777123456"}],
      "flow": [
        {
          "sms": {
            "sender": "MujObchod"
          }
        }
      ]
    }
    ```

    <Note>
      Alfanumerická jména odesílatele mohou v některých zemích vyžadovat předregistraci (například v České republice). Před odesíláním do těchto destinací kontaktujte podporu SmsManager pro registraci svého jména odesílatele nebo využijte objednávku online v administraci SmsManager po přihlášení do svého účtu.
    </Note>
  </Step>
  <Step title="Definujte typ gateway">
    Pole `gateway` uvnitř flow objektu `sms` říká, jak SmsManager směruje vaši zprávu. Ve výchozím nastavení není nutné toto uvádět a SmsManager hodnotu určí sám dle hodnoty "sender".

    | Brána | Popis |
    | --- | --- |
    | `high` | Výchozí. Nejlepší míra doručení přes agregátorskou síť. |
    | `lowcost` | Nízkonákladové směrování. |
    | `direct` | Vyžadována při použití dedikovaného virtuálního čísla jako odesílatele. Směruje přes přímé spojení operátorů. |
    | `custom` | SIM hostování, kdy poskytujete vlastní SIM hardware. |
    | `simhost` | SIM hostování (alternativa k `custom`). |
    | `gsm` | Směrování přes vlastní GSM bránu. |

    ```json Tělo požadavku
    {
      "body": "Váš ověřovací kód je 482910",
      "to": [{"phone_number": "420777123456"}],
      "flow": [
        {
          "sms": {
            "sender": "420600123456",
            "gateway": "direct"
          }
        }
      ]
    }
    ```
  </Step>
  <Step title="Zpracujte Unicode znaky">
      Standardní SMS používá znakovou sadu GSM-7. Pokud vaše zpráva obsahuje znaky mimo tuto sadu (například diakritiku nebo emoji) bude automaticky odstraněna. Přidejte `type: "utf"` do flow objektu `sms` pro zachování diakritiky.

    <Warning>
      Zprávy s diakritikou nebo emoji mají sníženou kapacitu 70 znaků na segment (oproti 160).
    </Warning>

    ```json Tělo požadavku
    {
      "body": "Ваш код подтверждения: 482910",
      "to": [{"phone_number": "79161234567"}],
      "flow": [
        {
          "sms": {
            "sender": "MujApp",
            "type": "utf"
          }
        }
      ]
    }
    ```
  </Step>
</Steps>

## Tagy

Pole `tag` klasifikuje vaši zprávu pro směrování a reporting. Zadává se na nejvyšší úrovni těla požadavku.

| Tag | Popis |
| --- | --- |
| `promotional` | Výchozí. Marketingové a hromadné zprávy. |
| `transactional` | Potvrzení objednávek, účtenky, upozornění účtu. |
| `priority` | Fronta s nejvyšší prioritou. Použijte pro časově citlivé OTP a upozornění. |

```json
{
  "body": "Váš přihlašovací kód je 291847",
  "to": [{"phone_number": "420777123456"}],
  "tag": "priority"
}
```

Tagy umožňují souhrně sledovat statisky doručení, nedoručení apod. To můžete použít pro sledování konkrétní kampaně a nebo typu zprávy:

```json
{
  "body": "Váš přihlašovací kód je 291847",
  "to": [{"phone_number": "420777123456"}],
  "tag": "priority,otp"
}
```

```json
{
  "body": "Váš přihlašovací kód je 291847",
  "to": [{"phone_number": "420777123456"}],
  "tag": "sms-kampan-1234"
}
```

## Doba života

Nastavte `ttl` (v minutách) uvnitř flow objektu `sms` pro řízení, jak dlouho se SmsManager pokouší o doručení před opuštěním zprávy. To je užitečné pro časově citlivé kódy, které jsou bezcenné po krátkém okně.

```json
{
  "body": "Váš jednorázový kód je 847201. Platnost 5 minut.",
  "to": [{"phone_number": "420777123456"}],
  "flow": [
    {
      "sms": {
        "sender": "MujApp",
        "ttl": 5
      }
    }
  ]
}
```

## Kompletní příklad

Následující příklady ukazují kompletní SMS požadavek s jménem odesílatele, tagem priority, TTL a callback URL pro doručení.

<CodeGroup>

```bash cURL
curl -X POST https://api.smsmngr.com/v2/message \
  -H "x-api-key: YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "body": "Váš přihlašovací kód je 482910. Platnost 10 minut.",
    "to": [{"phone_number": "420777123456"}],
    "tag": "priority",
    "callback": "https://yourapp.com/webhooks/sms",
    "flow": [
      {
        "sms": {
          "sender": "MujApp",
          "gateway": "high",
          "ttl": 10
        }
      }
    ]
  }'
```

```python Python
import requests

response = requests.post(
    "https://api.smsmngr.com/v2/message",
    headers={
        "x-api-key": "YOUR_API_KEY",
        "Content-Type": "application/json",
    },
    json={
        "body": "Váš přihlašovací kód je 482910. Platnost 10 minut.",
        "to": [{"phone_number": "420777123456"}],
        "tag": "priority",
        "callback": "https://yourapp.com/webhooks/sms",
        "flow": [
            {
                "sms": {
                    "sender": "MujApp",
                    "gateway": "high",
                    "ttl": 10,
                }
            }
        ],
    },
)

print(response.json())
```

```javascript Node.js
const response = await fetch("https://api.smsmngr.com/v2/message", {
  method: "POST",
  headers: {
    "x-api-key": "YOUR_API_KEY",
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
    body: "Váš přihlašovací kód je 482910. Platnost 10 minut.",
    to: [{ phone_number: "420777123456" }],
    tag: "priority",
    callback: "https://yourapp.com/webhooks/sms",
    flow: [
      {
        sms: {
          sender: "MujApp",
          gateway: "high",
          ttl: 10,
        },
      },
    ],
  }),
});

const data = await response.json();
console.log(data);
```
