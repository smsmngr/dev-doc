RCS (Rich Communication Services) je nástupce SMS s bohatým obsahem přímo v nativní aplikaci pro zprávy na Androidu. Přes SmsManager odešlete RCS zprávu objektem `rcs` uvnitř pole `flow` — od prostého textu a médií přes návrhy odpovědí a akční tlačítka až po rich card a carousel. Tato stránka je referenčním přehledem polí objektu `rcs`.

## Základní pole

| Pole | Typ | Popis |
| --- | --- | --- |
| `sender` | string | ID vašeho RCS agenta (odesílatele) nebo alias odesílatele. Krok ho potřebuje, ale nemusíte ho uvádět přímo v něm: pokud chybí, použije se `sender` z kořene požadavku a poté výchozí odesílatel vašeho účtu (`default_sender`). Viz [Odesílatelé](/concepts/senders). |
| `body` | string | Text zprávy. Nepovinné — zprávu můžete poslat i jen s médiem, kartou nebo carouselem. U zprávy s médiem slouží jako popisek (viz [Media](#media)). Pokud není uveden, použije se `body` z kořene požadavku. |
| `ttl` | integer | Doba života v **minutách**. Po jejím uplynutí se přejde na další krok `flow`. |

```json Prostý text
{
  "to": [{ "phone_number": "420777123456" }],
  "flow": [
    {
      "rcs": {
        "sender": "muj_rcs_agent",
        "body": "Ahoj! Vaše objednávka je připravena k vyzvednutí."
      }
    }
  ]
}
```

<Note>
  RCS zpráva se odešle jen příjemcům s aktivním RCS. Vždy zařaďte za RCS krok SMS zálohu ve [flow](/concepts/message-flow), aby zpráva dorazila i ostatním.
</Note>

## Media

Pole `image`, `video`, `document` a `audio` odešlou soubor z veřejné URL. Hodnotou je buď URL jako řetězec, nebo objekt `RcsMedia` s polem `url`.

| Pole | Příklady formátů |
| --- | --- |
| `image` | JPEG, PNG, GIF, WEBP |
| `video` | MP4, WEBM, 3GP |
| `document` | PDF |
| `audio` | MP3, OGG |

Objekt `RcsMedia` přijímá tato pole:

| Pole | Typ | Popis |
| --- | --- | --- |
| `url` | string | Veřejná URL souboru. Povinné. |
| `thumbnail` | string | Veřejná URL náhledu, který se zobrazí během načítání souboru. |
| `caption` | string | Popisek média. Pokud ho neuvedete, použije se `body`. |
| `height` | string | Výška média v rich card: `SHORT`, `MEDIUM` nebo `TALL`. Výchozí `MEDIUM`. Uplatní se jen tehdy, když se zpráva doručí jako rich card. |
| `forceRefresh` | boolean | Vynutí, aby si RCS platforma soubor stáhla znovu, i když má jeho kopii v cache. |

Způsob doručení závisí na textu:

- **Bez `caption` a bez `body`** se soubor odešle samostatně.
- **S `caption` nebo `body`** se zpráva doručí jako rich card a text se použije jako její popis.

V jedné zprávě použijte nejvýše jedno pole s médiem.

```json Samostatný obrázek
{
  "rcs": {
    "sender": "muj_rcs_agent",
    "image": "https://example.com/palubni-vstupenka.png"
  }
}
```

```json Obrázek jako rich card s popisem z body
{
  "rcs": {
    "sender": "muj_rcs_agent",
    "body": "Vaše palubní vstupenka",
    "image": "https://example.com/palubni-vstupenka.png"
  }
}
```

```json Video s náhledem a vlastním popiskem
{
  "rcs": {
    "sender": "muj_rcs_agent",
    "video": {
      "url": "https://example.com/navod.mp4",
      "thumbnail": "https://example.com/navod-nahled.jpg",
      "caption": "Jak sestavit stůl za 5 minut",
      "height": "TALL"
    }
  }
}
```

## Tlačítka (`buttons`)

Pole `buttons` přidá pod zprávu **návrhy odpovědí** (chipy). Každé tlačítko má `type` — buď `reply` (rychlá odpověď), nebo `url` (otevře odkaz).

| Pole tlačítka | Platí pro | Popis |
| --- | --- | --- |
| `type` | oba | `reply` nebo `url`. |
| `text` | oba | Popisek tlačítka. |
| `postback` | oba | Hodnota vrácená v příchozím webhooku, když příjemce na tlačítko klepne (`postbackData`). |
| `url` | `url` | Cílová URL. Povinné u tlačítek typu `url`. |
| `description` | `url` | Popis otevíraného odkazu. |
| `webview` | `url` | Otevře URL v in-app webview místo prohlížeče. Velikost určíte hodnotou `FULL`, `HALF` nebo `TALL` (`webviewViewMode`). |

```json
{
  "rcs": {
    "sender": "muj_rcs_agent",
    "body": "Jak vám můžeme pomoci?",
    "buttons": [
      { "type": "reply", "text": "Stav objednávky", "postback": "ORDER_STATUS" },
      { "type": "url", "text": "Otevřít e-shop", "postback": "OPEN_SHOP", "url": "https://example.com" }
    ]
  }
}
```

## Samostatná rich card (`card`)

Pole `card` odešle jednu kartu s obrázkem/videem, nadpisem, popisem a volitelnými tlačítky.

| Pole | Typ | Popis |
| --- | --- | --- |
| `title` | string | Nadpis karty. |
| `description` | string | Popis karty. |
| `file` | string | URL media (obrázek/video). |
| `thumbnail` | string | URL náhledu. |
| `height` | string | Výška média karty: `SHORT`, `MEDIUM` nebo `TALL`. Výchozí `MEDIUM`. |
| `buttons` | array | Tlačítka karty (stejný tvar jako výše). |

```json
{
  "rcs": {
    "sender": "muj_rcs_agent",
    "card": {
      "title": "Letní sleva",
      "description": "Sleva 20 % na celý sortiment do konce měsíce.",
      "file": "https://example.com/promo.jpg",
      "thumbnail": "https://example.com/promo-thumb.jpg",
      "buttons": [
        { "type": "url", "text": "Nakoupit", "postback": "SHOP", "url": "https://example.com/sale" }
      ]
    }
  }
}
```

## Carousel (`carousel`)

Pole `carousel` odešle vodorovně listovatelnou řadu **2 až 10** karet. Každá karta má stejná pole jako samostatná rich card:

| Pole | Typ | Popis |
| --- | --- | --- |
| `title` | string | Nadpis karty. |
| `description` | string | Popis karty. |
| `file` | string | URL media. |
| `thumbnail` | string | URL náhledu. |
| `height` | string | Výška média karty: `SHORT`, `MEDIUM` nebo `TALL`. Výchozí `MEDIUM`. |
| `buttons` | array | Tlačítka karty. |

```json
{
  "rcs": {
    "sender": "muj_rcs_agent",
    "carousel": [
      {
        "title": "Produkt A",
        "description": "Skladem",
        "file": "https://example.com/a.jpg",
        "thumbnail": "https://example.com/a-thumb.jpg",
        "buttons": [{ "type": "url", "text": "Detail", "postback": "A", "url": "https://example.com/a" }]
      },
      {
        "title": "Produkt B",
        "description": "Novinka",
        "file": "https://example.com/b.jpg",
        "thumbnail": "https://example.com/b-thumb.jpg"
      }
    ]
  }
}
```

## Raw průchozí zápis (`raw`)

Pro obsah, který toto rozhraní nepokrývá, předejte objekt `raw` — klíč `suggestions` pro vlastní návrhy nebo `richCard` pro vlastní kartu se odešle na RCS API beze změny.

```json
{
  "rcs": {
    "sender": "muj_rcs_agent",
    "body": "…",
    "raw": { "suggestions": [ { "reply": { "text": "Ano", "postbackData": "YES" } } ] }
  }
}
```
