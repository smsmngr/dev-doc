Tento průvodce vás provede odesláním první SMS pomocí SmsManager JSON API v2. Na konci budete mít úspěšné volání API, obdržíte `message_id` a budete vědět, kam pokračovat pro pokročilé funkce jako multikanálové toky a doručovací webhooky.

<Note>
  **Předpoklady:** Před začátkem potřebujete účet SmsManager a API klíč. Klíč získáte na [app.smsmanager.com/api-cloud](https://app.smsmanager.com/api-cloud).
</Note>

<Steps>
  <Step title="Získejte svůj API klíč">
    Přihlaste se ke svému účtu SmsManager a přejděte na [API & Cloud](https://app.smsmanager.com/api-cloud). Váš hlavní API klíč je zobrazen na této stránce. Zkopírujte jej — budete jej předávat jako hlavičku `x-api-key` v každém požadavku.

    Pokud potřebujete omezený klíč pro konkrétní integraci (například pro izolaci kreditu nebo zjednodušené odvolání), můžete si vytvořit sub-klíče přes [REST API](/cs/api-reference/rest/overview).
  </Step>
  <Step title="Odešlete první zprávu">
    Odešlete POST požadavek na `https://api.smsmngr.com/v2/message` s JSON tělem obsahujícím text zprávy a alespoň jedno telefonní číslo příjemce v mezinárodním formátu E.164 (bez úvodního `+` nebo `00`).

    **Tělo požadavku:**

    ```json
    {
      "body": "Ahoj od SmsManageru!",
      "to": [
        { "phone_number": "420777123456" }
      ]
    }
    ```

    **cURL:**

    ```bash
    curl -X POST https://api.smsmngr.com/v2/message \
      -H "x-api-key: YOUR_API_KEY" \
      -H "Content-Type: application/json" \
      -d '{"body": "Ahoj od SmsManageru!", "to": [{"phone_number": "420777123456"}]}'
    ```

    Nahraďte `YOUR_API_KEY` klíčem, který jste zkopírovali v kroku 1, a `420777123456` cílovým telefonním číslem.
  </Step>
  <Step title="Zkontrolujte odpověď">
    Úspěšný požadavek vrací HTTP `200` s JSON tělem podobným následujícímu:

    ```json
    {
      "request_id": "bc36f3d1-d284-463a-921b-a3560c154649",
      "accepted": [
        { "key": "0", "message_id": "e27ff0ac-87b5-4e1d-b644-5fc6029e2a11" }
      ],
      "rejected": []
    }
    ```

    - **`request_id`** — jedinečný identifikátor celého API volání. Použijte jej pro korelaci požadavků ve vašich logech.
    - **`message_id`** — jedinečný identifikátor konkrétní zprávy odeslané konkrétnímu příjemci. Uložte tuto hodnotu, pokud chcete propojit události doručení webhookem s původním odesláním.
    - **`rejected`** — pole příjemců, kteří nebyli přijati (například kvůli neplatnému formátu telefonního čísla). Prázdné pole znamená, že všichni příjemci byli přijati.
  </Step>
  <Step title="Nastavte webhook (volitelné)">
    Chcete-li přijímat aktualizace doručení v reálném čase, přidejte do těla požadavku URL `callback`. SmsManager pošle POST oznámení o doručení na tuto URL při každé změně stavu zprávy (doručeno, selhalo atd.).

    ```json
    {
      "body": "Ahoj od SmsManageru!",
      "to": [{ "phone_number": "420777123456" }],
      "callback": "https://your-app.example.com/webhooks/sms"
    }
    ```

    Přečtěte si [průvodce Webhooky](/cs/guides/webhooks) pro celé schéma payload událostí a detaily ověření.
  </Step>
</Steps>

## Ukázky kódu

Následující ukázky odesílají stejnou základní zprávu. Vyberte jazyk, který odpovídá vašemu stacku.

<CodeGroup>

```bash cURL
curl -X POST https://api.smsmngr.com/v2/message \
  -H "x-api-key: YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "body": "Ahoj od SmsManageru!",
    "to": [{"phone_number": "420777123456"}]
  }'
```

```python Python
import requests

url = "https://api.smsmngr.com/v2/message"
headers = {
    "x-api-key": "YOUR_API_KEY",
    "Content-Type": "application/json",
}
payload = {
    "body": "Ahoj od SmsManageru!",
    "to": [{"phone_number": "420777123456"}],
}

response = requests.post(url, json=payload, headers=headers)
print(response.json())
```

```javascript Node.js
const response = await fetch("https://api.smsmngr.com/v2/message", {
  method: "POST",
  headers: {
    "x-api-key": "YOUR_API_KEY",
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
    body: "Ahoj od SmsManageru!",
    to: [{ phone_number: "420777123456" }],
  }),
});

const data = await response.json();
console.log(data);
```

```php PHP
<?php

$payload = json_encode([
    "body" => "Ahoj od SmsManageru!",
    "to"   => [["phone_number" => "420777123456"]],
]);

$ch = curl_init("https://api.smsmngr.com/v2/message");
curl_setopt($ch, CURLOPT_RETURNTRANSFER, true);
curl_setopt($ch, CURLOPT_POST, true);
curl_setopt($ch, CURLOPT_POSTFIELDS, $payload);
curl_setopt($ch, CURLOPT_HTTPHEADER, [
    "x-api-key: YOUR_API_KEY",
    "Content-Type: application/json",
]);

$response = curl_exec($ch);
curl_close($ch);
echo $response;
```

</CodeGroup>
