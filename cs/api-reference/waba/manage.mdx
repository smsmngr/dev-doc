Poté, co klient dokončí WABA onboarding, použijte tyto tři endpointy k získání detailů jeho účtu, aktivních telefonních čísel a schválených šablon zpráv. Všechny tři sledují stejný vzor: POST `waba_id` k filtrování výsledků, nebo pon echte tělo prázdné pro vrácení všech záznamů spojených s vaším partnerským účtem.

---

## POST /whatsapp/accounts/list

Získat WABA účty registrované pod vaším partnerským účtem. Použijte `whatsapp_id` z odpovědi jako vstup `waba_id` pro endpointy telefonních čísel a šablon.

### Endpoint

```text
POST https://rest-api.smsmngr.com/v1/whatsapp/accounts/list
```

### Tělo požadavku

<ParamField body="waba_id" type="string">
  Filtrovat výsledky na jediný WABA podle jeho ID. Ponechte prázdné nebo vynechte pro vrácení všech účtů spojených s vaším partnerským API klíčem.
</ParamField>

### Pole odpovědi

<ResponseField name="success" type="boolean">
  `true`, když byl požadavek dokončen úspěšně.
</ResponseField>

<ResponseField name="accounts" type="array">
  Pole objektů WABA účtů.

  <Expandable title="pole objektu účtu">
    <ResponseField name="client_id" type="string">
      `partner_client_id`, který jste zadali při volání signup. Použijte to k párování účtu zpět na váš interní záznam klienta.
    </ResponseField>

    <ResponseField name="whatsapp_name" type="string">
      Zobrazované WhatsApp / firemní jméno pro tento účet.
    </ResponseField>

    <ResponseField name="whatsapp_id" type="string">
      WABA ID přiřazené Metou. Použijte tuto hodnotu jako `waba_id` při volání endpointů pro listing telefonních čísel a šablon.
    </ResponseField>

    <ResponseField name="whatsapp_currency" type="string">
      Fakturační měna pro toto WABA (např. `USD`, `EUR`, `GBP`).
    </ResponseField>

    <ResponseField name="whatsapp_owner_name" type="string">
      Název firmy nebo entity, která vlastní Meta Business účet.
    </ResponseField>

    <ResponseField name="whatsapp_owner_id" type="string">
      ID Meta Business účtu vlastníka.
    </ResponseField>

    <ResponseField name="country" type="string">
      Země spojená s WABA ve formátu ISO alpha-2.
    </ResponseField>
  </Expandable>
</ResponseField>

### Příklad

<CodeGroup>

```bash cURL
curl -X POST https://rest-api.smsmngr.com/v1/whatsapp/accounts/list \
  -H "Content-Type: application/json" \
  -H "x-api-key: <your-api-key>" \
  -d '{ "waba_id": "123456789" }'
```

```json Tělo požadavku
{
  "waba_id": "123456789"
}
```

```json Odpověď
{
  "success": true,
  "accounts": [
    {
      "client_id": "client-789",
      "whatsapp_name": "Acme Support",
      "whatsapp_id": "123456789",
      "whatsapp_currency": "USD",
      "whatsapp_owner_name": "Acme Corp",
      "whatsapp_owner_id": "987654321",
      "country": "US"
    }
  ]
}
```

</CodeGroup>

## POST /whatsapp/phone\_numbers/list

Získat telefonní čísla registrovaná pod konkrétním WABA. `phone_number_id` zde vrácené je hodnota, kterou použijete jako pole `sender` při odesílání WhatsApp zpráv přes SmsManager JSON API v2.

### Endpoint

```text
POST https://rest-api.smsmngr.com/v1/whatsapp/phone_numbers/list
```

### Tělo požadavku

<ParamField body="waba_id" type="string">
  WABA ID, pro které chcete vypsat telefonní čísla. Získejte jej z pole `whatsapp_id` v odpovědi list účtů.
</ParamField>

### Pole odpovědi

<ResponseField name="success" type="boolean">
  `true`, když byl požadavek dokončen úspěšně.
</ResponseField>

<ResponseField name="phone_numbers" type="array">
  Pole objektů telefonních čísel.

  <Expandable title="pole objektu telefonního čísla">
    <ResponseField name="phone_number" type="string">
      Plné telefonní číslo v mezinárodním formátu.
    </ResponseField>

    <ResponseField name="phone_number_id" type="string">
      Identifikátor tohoto telefonního čísla přidělený Metou. Předejte tuto hodnotu jako parametr `sender` při odesílání `whatsapp_text` nebo `whatsapp_template` zpráv přes JSON API v2.
    </ResponseField>

    <ResponseField name="status" type="string">
      Aktuální stav telefonního čísla (např. `CONNECTED`, `PENDING`).
    </ResponseField>
  </Expandable>
</ResponseField>

### Příklad

<CodeGroup>

```bash cURL
curl -X POST https://rest-api.smsmngr.com/v1/whatsapp/phone_numbers/list \
  -H "Content-Type: application/json" \
  -H "x-api-key: <your-api-key>" \
  -d '{ "waba_id": "123456789" }'
```

```json Tělo požadavku
{
  "waba_id": "123456789"
}
```

```json Odpověď
{
  "success": true,
  "phone_numbers": [
    {
      "phone_number": "+14155550100",
      "phone_number_id": "10634195021",
      "status": "CONNECTED"
    }
  ]
}
```

</CodeGroup>

## POST /whatsapp/templates/list

Získat šablony zpráv schválené pro WABA. Pouze šablony se stavem `APPROVED` lze použít ve zprávách `whatsapp_template` odeslaných přes JSON API v2.

### Endpoint

```text
POST https://rest-api.smsmngr.com/v1/whatsapp/templates/list
```

### Tělo požadavku

<ParamField body="waba_id" type="string">
  WABA ID, pro které chcete vypsat šablony.
</ParamField>

### Pole odpovědi

<ResponseField name="success" type="boolean">
  `true`, když byl požadavek dokončen úspěšně.
</ResponseField>

<ResponseField name="templates" type="array">
  Pole objektů šablon.

  <Expandable title="pole objektu šablony">
    <ResponseField name="template_name" type="string">
      Název šablony, jak byla registrována s Metou.
    </ResponseField>

    <ResponseField name="status" type="string">
      Stav schválení šablony. Běžné hodnoty zahrnují `APPROVED`, `PENDING` a `REJECTED`. Pouze `APPROVED` šablony lze poslat uživatelům.
    </ResponseField>
  </Expandable>
</ResponseField>

### Příklad

<CodeGroup>

```bash cURL
curl -X POST https://rest-api.smsmngr.com/v1/whatsapp/templates/list \
  -H "Content-Type: application/json" \
  -H "x-api-key: <your-api-key>" \
  -d '{ "waba_id": "123456789" }'
```

```json Tělo požadavku
{
  "waba_id": "123456789"
}
```

```json Odpověď
{
  "success": true,
  "templates": [
    {
      "template_name": "order_confirmation",
      "status": "APPROVED"
    },
    {
      "template_name": "shipping_update",
      "status": "APPROVED"
    },
    {
      "template_name": "promotional_offer",
      "status": "PENDING"
    }
  ]
}
```

</CodeGroup>

<Tip>
  Získejte `phone_number_id` ze seznamu telefonních čísel a použijte jej jako pole `sender` při odesílání WhatsApp zpráv přes SmsManager JSON API v2. To platí pro oba typy zpráv `whatsapp_text` a `whatsapp_template`.
</Tip>
