Tyto endpointy vám umožňují spravovat API klíče pro váš SmsManager účet. Můžete zkontrolovat nastavení aktuálního klíče, vytvářet sub-klíče pro multi-tenant integrace nebo samostatné fakturace a aktualizovat konfiguraci na úrovni klíče, jako je výchozí webhook callback URL.

---

## GET /apikey/me

Získat informace o API klíči, který právě používáte.

**Endpoint:** `GET https://rest-api.smsmngr.com/v1/apikey/me`

**Autentizace:** vyžaduje hlavičku `x-api-key`.

**Parametry požadavku:** žádné.

### Odpověď

<ResponseField name="success" type="boolean" required>
  `true`, když požadavek uspěl.
</ResponseField>

<ResponseField name="me" type="object" required>
  Detaily o aktuálním API klíči.

  <Expandable title="vlastnosti me">
    <ResponseField name="note" type="string">
      Váš popisek pro tento klíč. Může být prázdný. Můžete jej nastavit přes `POST /apikey/update`.
    </ResponseField>

    <ResponseField name="default_callback_url" type="string">
      Výchozí webhook URL používaná pro příchozí zprávy, které nemají vztah k žádné odchozí zprávě.
    </ResponseField>

    <ResponseField name="account" type="string">
      Typ fakturace účtu. Jeden z `prepaid` nebo `postpaid`.
    </ResponseField>
  </Expandable>
</ResponseField>

### Příkladová odpověď

```json
{
  "success": true,
  "me": {
    "note": "Produkční klíč",
    "default_callback_url": "https://example.com/webhook",
    "account": "prepaid"
  }
}
```

### cURL příklad

```bash
curl https://rest-api.smsmngr.com/v1/apikey/me \
  -H "x-api-key: YOUR_API_KEY"
```

## POST /apikey/add

Vytvořte nový sub-klíč pod svým účtem. To je užitečné pro multi-tenant aplikace, kde každý zákazník potřebuje vlastní klíč, nebo když chcete izolovat fakturaci pro různé služby.

**Endpoint:** `POST https://rest-api.smsmngr.com/v1/apikey/add`

**Autentizace:** vyžaduje hlavičku `x-api-key`.

### Tělo požadavku

<ParamField body="shared" type="boolean">
  Pokud `true`, nový klíč sdílí kreditní zůstatek nadřazeného klíče. Pokud `false`, nový klíč má svůj vlastní samostatný kreditní zůstatek.
</ParamField>

<ParamField body="currency" default="CZK" type="string">
  Měna pro kreditní zůstatek nového klíče. Přijaté hodnoty: `EUR`, `CZK`. Relevantní pouze pokud `shared` je `false`.
</ParamField>

<Warning>
  Když `shared` je `true`, `currency` musí odpovídat měně vašeho nadřazeného klíče. Neshodné měny povedou k chybě.
</Warning>

### Odpověď

<ResponseField name="success" type="boolean" required>
  `true`, když byl klíč úspěšně vytvořen.
</ResponseField>

<ResponseField name="apikey" type="string" required>
  Nově vytvořený řetězec API klíče.
</ResponseField>

### Příklad požadavku a odpovědi

```json
// Tělo požadavku
{
  "shared": false,
  "currency": "EUR"
}
```

```json
// Odpověď
{
  "success": true,
  "apikey": "new_api_key_here"
}
```

### cURL příklad

```bash
curl -X POST https://rest-api.smsmngr.com/v1/apikey/add \
  -H "x-api-key: YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"shared": false, "currency": "EUR"}'
```

## POST /apikey/update

Aktualizujte nastavení API klíče, který právě používáte. Můžete změnit výchozí webhook URL pro příchozí zprávy a nastavit čitelný popisek (poznámku) pro klíč.

**Endpoint:** `POST https://rest-api.smsmngr.com/v1/apikey/update`

**Autentizace:** vyžaduje hlavičku `x-api-key`.

### Tělo požadavku

<ParamField body="default_callback_url" type="string">
  Webhook URL, která se volá, když přijde příchozí zpráva, která nemá vztah k dříve odeslané odchozí zprávě.
</ParamField>

<ParamField body="note" type="string">
  Čitelný popisek pro tento klíč. Užitečné pro identifikaci klíčů v dashboardu nebo přes `GET /apikey/me`.
</ParamField>

### Odpověď

<ResponseField name="success" type="boolean" required>
  `true`, když byl klíč úspěšně aktualizován.
</ResponseField>

### Příklad požadavku a odpovědi

```json
// Tělo požadavku
{
  "default_callback_url": "https://example.com/webhook",
  "note": "Produkční klíč"
}
```

```json
// Odpověď
{
  "success": true
}
```

### cURL příklad

```bash
curl -X POST https://rest-api.smsmngr.com/v1/apikey/update \
  -H "x-api-key: YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"default_callback_url": "https://example.com/webhook", "note": "Produkční klíč"}'
```
