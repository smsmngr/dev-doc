Před odesláním velké dávky zpráv můžete zkontrolovat svůj zbývající prepaid kreditní zůstatek, abyste se ujistili, že máte dostatek prostředků. Tento endpoint vrací zůstatky v obou měnách — české koruně (CZK) i euru (EUR) — současně, takže vždy máte aktuální přehled bez ohledu na to, ve které měně váš účet operuje.

## Endpoint

```text
GET https://rest-api.smsmngr.com/v1/credit
```

## Autentizace

Zahrňte váš API klíč v hlavičce požadavku `x-api-key`.

```http
x-api-key: YOUR_API_KEY
```

## Parametry požadavku

Tento endpoint neběre žádné query parametry ani tělo požadavku.

## Odpověď

<ResponseField name="success" type="boolean" required>
  `true`, když požadavek uspěl.
</ResponseField>

<ResponseField name="credit" type="object" required>
  Vaše aktuální kreditní zůstatky.

  <Expandable title="vlastnosti credit">
    <ResponseField name="credit_czk" type="number" required>
      Zbývající kreditní zůstatek v českých korunách (CZK).
    </ResponseField>

    <ResponseField name="credit_eur" type="number" required>
      Zbývající kreditní zůstatek v eurech (EUR).
    </ResponseField>
  </Expandable>
</ResponseField>

### Příkladová odpověď

```json
{
  "success": true,
  "credit": {
    "credit_czk": 1234.50,
    "credit_eur": 49.38
  }
}
```

## cURL příklad

```bash
curl https://rest-api.smsmngr.com/v1/credit \
  -H "x-api-key: YOUR_API_KEY"
```

## Chybové odpovědi

Pokud požadavek selže, API vrací HTTP `400` s JSON chybovým tělem.

```json
{
  "success": false,
  "message": "Failed to read credit balance"
}
```

<Tip>
  Sledujte `credit_czk` nebo `credit_eur` ve vaší aplikaci a spouštějte upozornění, když zůstatek klesne pod práh. To zabraňuje přerušení služby způsobených prázdným prepaid zůstatkem.
</Tip>

<Note>
  Postpaid účty mohou vždy zobrazovat `0` v obou polech kreditu. Pokud váš účet používá postpaid fakturaci a potřebujete informace o zůstatku nebo fakturách, kontaktujte [podporu SmsManager](mailto:cc@smsmanager.cz).
</Note>
