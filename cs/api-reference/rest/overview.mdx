SmsManager REST API je samostatné API oddělené od JSON API v2 (odesílací API). Zatímco JSON API v2 zpracovává doručování odchozích zpráv, REST API pokrývá vše kolem vašeho účtu. Můžete vytvářet a spravovat API klíče (včetně podřízených klíčů), pracovat s kreditem — procházet katalog služeb a ceník, zjistit svou cenu pro konkrétní destinaci, nastavovat upozornění na nízký kredit a objednávat, vypisovat nebo rušit placené služby — a řešit fakturaci, od fakturačního kontaktu a faktur (včetně stahování PDF) až po dobití bankovním převodem. Dále umožňuje sledovat stav zpráv a statistiky odesílání, číst příchozí zprávy ve vaší schránce, spravovat blacklist a opt-out seznamy, ověřovat zprávy bez odeslání, spouštět hromadné odesílání a registrovat push zařízení a příjemce.

## Základní URL

Všechny požadavky REST API se provádějí na:

```text
https://rest-api.smsmngr.com/v1
```

## Autentizace

Každý požadavek musí obsahovat váš API klíč v hlavičce požadavku `x-api-key`. Je to stejný API klíč, který používáte s JSON API v2.

```http
x-api-key: YOUR_API_KEY
```

Své API klíče můžete najít a spravovat v sekci [Vývojáři](https://app.smsmanager.com/app/developers/) v SmsManager Dashboardu.

### Hromadné odesílání

Nahrajte JSONL soubor s tisíci zpráv přes předpodepsanou URL místo tisíců volání odesílacího API. Celý postup najdete v průvodci [Hromadné odesílání](/guides/batch-sending#hromadné-nahrání-souboru-přes-rest-api).

Strukturu jedné zprávy nebo pole až 10 zpráv si před odesláním ověříte přes `/messaging/validate`. Nic se neodešle ani neúčtuje. Podrobnosti najdete v průvodci [Testování napojení](/guides/testing#validace-bez-odeslání).

| Metoda | Endpoint | Popis |
| --- | --- | --- |
| `POST` | `/messaging/url` | Získat URL pro hromadné nahrání |
| `POST` | `/messaging/validate` | Ověřit zprávy bez odeslání |
| `POST` | `/messaging/cancel` | Zrušit naplánovanou zprávu nebo hromadné nahrání |

## Pro AI agenty

Stav zpráv, schránku, opt-out seznamy, objednávání služeb i hromadné nahrávání pokrývají skills `smsmanager-message-status`, `smsmanager-optout-blacklist`, `smsmanager-services` a `smsmanager-bulk-messaging` z balíčku [SmsManager skills](/ai/skills). Správu klíčů, kreditu, fakturace a služeb zvládne AI asistent i přímo přes [MCP server](/ai/mcp-server) s OAuth přihlášením.
