SmsManager REST API je samostatné API oddělené od JSON API v2 (odesílací API). Zatímco JSON API v2 zpracovává doručování odchozích zpráv, REST API pokrývá vše kolem vašeho účtu. Můžete vytvářet a spravovat API klíče (včetně podřízených klíčů), pracovat s kreditem — procházet katalog služeb a ceník, nastavovat upozornění na nízký kredit a objednávat nebo rušit placené služby — a řešit fakturaci, od fakturačního kontaktu a faktur (včetně stahování PDF) až po dobití bankovním převodem. Dále umožňuje sledovat stav zpráv a statistiky odesílání, číst příchozí zprávy ve vaší schránce, spravovat blacklist a opt-out seznamy, spouštět hromadné odesílání a propojovat partnerské účty a platformové integrace.

## Základní URL

Všechny požadavky REST API se provádějí na:

```text
https://rest-api.smsmngr.com/v1
```

## Autentizace

Každý požadavek musí obsahovat váš API klíč v hlavičce požadavku `x-api-key`. Je to stejný API klíč, který používáte s JSON API v2.

```http
x-api-key: YOUR_API_KEY
```

Své API klíče můžete najít a spravovat v [SmsManager Dashboardu](https://app.smsmanager.com).

| --- | --- | --- |
