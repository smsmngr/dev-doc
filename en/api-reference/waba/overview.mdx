SmsManager's WhatsApp Business Partner API gives you a programmatic way to register your clients for WhatsApp Business messaging, track their onboarding progress, and then run their WhatsApp Business Accounts end to end — retrieving phone numbers, managing the full lifecycle of message templates, and reading messaging analytics — all under your partner credentials.

## Who is this API for?

If you are an ISV, reseller, or platform builder integrating WhatsApp messaging into a product you offer to your own customers, this API is for you. You initiate registration on your client's behalf, redirect them to a SmsManager-hosted flow (or complete onboarding programmatically) where they register their WhatsApp Business Account (WABA), and then use the management endpoints to run it.

The API is no longer onboarding-only. Beyond signup and account lookup, it now covers:

- **Message-template management** — create templates, create them from the Meta Template Library, edit, delete, and send live test messages.
- **Analytics** — messaging analytics (sent / delivered), conversation analytics (counts and costs), and per-template performance (sent, delivered, read, clicked).

Everything runs under your partner account — your clients never need direct access to SmsManager.

## Base URL

```text
https://rest-api.smsmngr.com/v1
```

## Authentication

All endpoints require your API key in the `x-api-key` request header.

```http
x-api-key: <your-api-key>
```

Several management endpoints (phone numbers, templates, analytics) also accept a short-lived `token` in the request body as an alternative authentication — the same signup token returned by `POST /whatsapp/signup` (valid 1 hour). Use it when you drive these calls from the hosted signup flow instead of your API key.

## Onboarding flow

1. **POST /whatsapp/signup** — Send your client's details to SmsManager. You receive a `redirect_url` and a short-lived JWT `token`.
2. **Redirect your client** — Append the token as a query parameter and send the client's browser to `redirect_url?token=<JWT>`. SmsManager serves the hosted registration UI.
3. **Client completes registration** — The client follows the WhatsApp Business registration steps in the SmsManager-hosted flow. No coding required on their end.
4. **Complete registration** — Onboarding can also be finished programmatically with `POST /whatsapp/registration`, which exchanges the Meta OAuth `code`, connects the WABA, and registers the phone number.
5. **Receive callback** — SmsManager posts onboarding status notifications to the `partner_callback_url` you supplied in step 1. Listen for the completion event.
6. **Retrieve the WABA ID** — Call `POST /whatsapp/accounts/list` to get the new account's `whatsapp_id` (WABA ID).
7. **Manage phone numbers and templates** — Use the WABA ID with `POST /whatsapp/phone_numbers/list` and `POST /whatsapp/templates/list` to retrieve the resources you need for sending messages.

The `phone_number` mode you request at signup is now one of `manual` (the client connects their own number), `preassign` (a number from our pool is pre-assigned), or `assigned` (an already assigned number is used). The old `automatic` value is gone.

## Endpoints summary

### WhatsApp accounts

| Method | Path | Description |
| --- | --- | --- |
| `POST` | `/whatsapp/signup` | Start WhatsApp embedded signup |
| `POST` | `/whatsapp/registration` | Complete WhatsApp registration |
| `POST` | `/whatsapp/accounts/list` | List connected WhatsApp accounts |

### Phone numbers

| Method | Path | Description |
| --- | --- | --- |
| `POST` | `/whatsapp/phone_numbers/verify` | Forward phone number verification code |
| `POST` | `/whatsapp/phone_numbers/check` | Check phone number availability |
| `POST` | `/whatsapp/phone_numbers/list` | List phone numbers of a WABA |

### Message templates

| Method | Path | Description |
| --- | --- | --- |
| `POST` | `/whatsapp/templates/list` | List message templates |
| `POST` | `/whatsapp/templates/create` | Create message template |
| `POST` | `/whatsapp/templates/library/create` | Create template from Meta library |
| `POST` | `/whatsapp/templates/edit` | Edit message template |
| `POST` | `/whatsapp/templates/delete` | Delete message template |
| `POST` | `/whatsapp/templates/test` | Send a test template message |

### Analytics

| Method | Path | Description |
| --- | --- | --- |
| `POST` | `/whatsapp/analytics/messages` | Get messaging analytics |
| `POST` | `/whatsapp/analytics/conversations` | Get conversation analytics |
| `POST` | `/whatsapp/analytics/templates` | Get template analytics |
| `POST` | `/whatsapp/analytics/templates/enable` | Enable template insights |
