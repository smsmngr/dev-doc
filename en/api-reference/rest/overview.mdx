The SmsManager REST API is a separate API from the JSON API v2 (the sending API). While the JSON API v2 handles outbound message delivery, the REST API covers everything around your account. You can create and manage API keys (including child keys), work with credit — browse the service catalog and price list, look up your price for a specific destination, set low-credit alerts, and order, list or cancel paid services — and handle billing, from your billing contact and invoices (including PDF downloads) to bank-transfer top-ups. It also lets you track message status and sending statistics, read inbound messages in your inbox, maintain your blacklist and opt-out lists, validate messages without sending, run bulk and high-volume messaging, and register push devices and recipients.

## Base URL

All REST API requests are made to:

```text
https://rest-api.smsmngr.com/v1
```

## Authentication

Every request must include your API key in the `x-api-key` request header. This is the same API key you use with the JSON API v2.

```http
x-api-key: YOUR_API_KEY
```

You can find and manage your API keys on the [Developers](https://app.smsmanager.com/app/developers/) page of the SmsManager Dashboard.

## Endpoints

### API keys

| Method | Endpoint | Description |
| --- | --- | --- |
| `GET` | `/apikey/me` | Get current API key info |
| `POST` | `/apikey/add` | Create a child API key |
| `POST` | `/apikey/update` | Update an API key (incl. child keys) |
| `GET` | `/apikey/list` | List child API keys |
| `POST` | `/apikey/change` | Change a child API key (deprecated — use `/apikey/update` with the `apikey` field) |

### Credit

To order a sender or a phone number and manage your orders, see the [Ordering senders and numbers](/guides/order-services) guide.

| Method | Endpoint | Description |
| --- | --- | --- |
| `GET` | `/credit` | Get credit balance |
| `GET` | `/credit/services` | Get service catalog |
| `GET` | `/credit/prices` | Get price list |
| `POST` | `/credit/price` | Get price for a destination |
| `GET` | `/credit/notify` | Get low-credit notification settings |
| `POST` | `/credit/notify` | Set low-credit notification |
| `GET` | `/credit/orders` | List ordered services |
| `POST` | `/credit/order` | Order a paid service |
| `POST` | `/credit/cancel` | Cancel a paid service |

### Billing

| Method | Endpoint | Description |

### Message status

| Method | Endpoint | Description |
| --- | --- | --- |
| `GET` | `/message` | Get message status |
| `GET` | `/messages` | List sent messages by date |
| `GET` | `/request` | Get request statistics |
| `GET` | `/requests` | Get aggregated statistics per date |

### Inbox

| Method | Endpoint | Description |
| --- | --- | --- |
| `GET` | `/inbox` | Get inbox messages by date |

### Blacklist & opt-out

| Method | Endpoint | Description |
| --- | --- | --- |
| `GET` | `/blacklist` | Download blacklist |
| `POST` | `/blacklist` | Add numbers to blacklist |
| `DELETE` | `/blacklist` | Remove numbers from blacklist |
| `GET` | `/optout` | Download opt-out list |
| `POST` | `/optout` | Add numbers to opt-out list |
| `DELETE` | `/optout` | Remove numbers from opt-out list |

### Bulk messaging

Upload a JSONL file with thousands of messages via a presigned URL instead of making thousands of sending API calls. See the [Batch sending guide](/guides/batch-sending#bulk-file-upload-via-the-rest-api) for the end-to-end workflow.

To check the structure of one message or an array of up to 10 messages before you send them, call `/messaging/validate`. Nothing is sent or charged. See [Testing your integration](/guides/testing#validation-without-sending) for details.

| Method | Endpoint | Description |
| --- | --- | --- |
| `POST` | `/messaging/url` | Get bulk upload URL |
| `POST` | `/messaging/validate` | Validate messages without sending |
| `POST` | `/messaging/cancel` | Cancel a scheduled message or bulk upload |

### Devices & recipients

These endpoints register devices for push notifications, and message recipients with their phone number and push tokens.

| Method | Endpoint | Description |
| --- | --- | --- |
| `POST` | `/push/device` | Register push device |
| `POST` | `/recipient/register` | Register recipient |

## For AI agents

Message status, the inbox, opt-out lists, service ordering and bulk uploads are covered by the `smsmanager-message-status`, `smsmanager-optout-blacklist`, `smsmanager-services` and `smsmanager-bulk-messaging` skills from the [SmsManager skills](/ai/skills) package. An AI assistant can also manage keys, credit, billing and services directly through the [MCP server](/ai/mcp-server) with OAuth sign-in.
