The SmsManager REST API is a separate API from the JSON API v2 (the sending API). While the JSON API v2 handles outbound message delivery, the REST API covers everything around your account. You can create and manage API keys (including child keys), work with credit — browse the service catalog and price list, set low-credit alerts, and order or cancel paid services — and handle billing, from your billing contact and invoices (including PDF downloads) to bank-transfer top-ups. It also lets you track message status and sending statistics, read inbound messages in your inbox, maintain your blacklist and opt-out lists, run bulk and high-volume messaging, and connect partner accounts and platform integrations.

## Base URL

All REST API requests are made to:

```text
https://rest-api.smsmngr.com/v1
```

## Authentication

Every request must include your API key in the `x-api-key` request header. This is the same API key you use with the JSON API v2.

```http
x-api-key: YOUR_API_KEY
```

You can find and manage your API keys in the [SmsManager Dashboard](https://app.smsmanager.com).

## Endpoints

### API keys

| Method | Endpoint | Description |
| --- | --- | --- |
| `GET` | `/apikey/me` | Get current API key info |
| `POST` | `/apikey/add` | Create a child API key |
| `POST` | `/apikey/update` | Update current API key |
| `GET` | `/apikey/list` | List child API keys |
| `POST` | `/apikey/change` | Change a child API key |

### Credit

| Method | Endpoint | Description |
| --- | --- | --- |
| `GET` | `/credit` | Get credit balance |
| `GET` | `/credit/services` | Get service catalog |
| `GET` | `/credit/prices` | Get price list |
| `GET` | `/credit/notify` | Get low-credit notification settings |
| `POST` | `/credit/notify` | Set low-credit notification |
| `POST` | `/credit/order` | Order a paid service |
| `POST` | `/credit/cancel` | Cancel a paid service |

### Billing

| Method | Endpoint | Description |
| --- | --- | --- |
| `POST` | `/billing/get` | Get billing contact |
| `POST` | `/billing/set` | Set billing contact |
| `POST` | `/billing/invoices/list` | List invoices |
| `POST` | `/billing/invoices/pdf` | Download invoice PDF |
| `GET` | `/billing/topup` | Get bank transfer top-up details |

### Message status

| Method | Endpoint | Description |
| --- | --- | --- |
| `GET` | `/message` | Get message status |
| `GET` | `/messages` | List sent messages by date |
| `GET` | `/request` | Get request statistics |
| `GET` | `/requests` | Get aggregated statistics per date |

### Inbox

| Method | Endpoint | Description |
| --- | --- | --- |
| `GET` | `/inbox` | Get inbox messages by date |

### Blacklist & opt-out

| Method | Endpoint | Description |
| --- | --- | --- |
| `GET` | `/blacklist` | Download blacklist |
| `POST` | `/blacklist` | Add numbers to blacklist |
| `DELETE` | `/blacklist` | Remove numbers from blacklist |
| `GET` | `/optout` | Download opt-out list |
| `POST` | `/optout` | Add numbers to opt-out list |
| `DELETE` | `/optout` | Remove numbers from opt-out list |

### Bulk messaging

| Method | Endpoint | Description |
| --- | --- | --- |
| `POST` | `/messaging/url` | Get bulk upload URL |
| `POST` | `/messaging/cancel` | Cancel a scheduled message or bulk upload |

### Partner & integrations

These endpoints are intended for partner accounts and platform integrations — partner signup, device push registration, recipient registration, and third-party connector actions (such as Klaviyo).

| Method | Endpoint | Description |
| --- | --- | --- |
| `POST` | `/partner/signup` | Start partner signup flow |
| `POST` | `/push/device` | Register push device |
| `POST` | `/recipient/register` | Register recipient |
| `POST` | `/connect/{connector}/{action}` | Connector action |
