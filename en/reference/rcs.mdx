RCS (Rich Communication Services) is the successor to SMS, delivering rich content directly in the native messaging app on Android. With SmsManager you send an RCS message using the `rcs` object inside the `flow` array — from plain text and media through reply suggestions and action buttons all the way to rich cards and carousels. This page is a reference overview of the fields of the `rcs` object.

## Basic fields

| Field | Type | Description |
| --- | --- | --- |
| `sender` | string | The ID of your RCS agent (sender), or a sender alias. The step needs one, but you don't have to set it in the step itself: if it's missing, the `sender` from the root of the request is used, then your account's default sender (`default_sender`). See [Senders](/concepts/senders). |
| `body` | string | The message text. Optional — you can send a message with only media, a card, or a carousel. In a media message it serves as the caption (see [Media](#media)). If omitted, the `body` from the root of the request is used. |
| `ttl` | integer | Time to live in **minutes**. Once it elapses, the flow advances to the next `flow` step. |

```json Plain text
{
  "to": [{ "phone_number": "420777123456" }],
  "flow": [
    {
      "rcs": {
        "sender": "muj_rcs_agent",
        "body": "Ahoj! Vaše objednávka je připravena k vyzvednutí."
      }
    }
  ]
}
```

<Note>
  An RCS message is delivered only to recipients with RCS enabled. Always place an SMS fallback after the RCS step in your [flow](/concepts/message-flow) so the message reaches everyone else too.
</Note>

## Media

The `image`, `video`, `document`, and `audio` fields send a file from a public URL. The value is either the URL as a string or an `RcsMedia` object with a `url` field.

| Field | Example formats |
| --- | --- |
| `image` | JPEG, PNG, GIF, WEBP |
| `video` | MP4, WEBM, 3GP |
| `document` | PDF |
| `audio` | MP3, OGG |

The `RcsMedia` object accepts these fields:

| Field | Type | Description |
| --- | --- | --- |
| `url` | string | The public URL of the file. Required. |
| `thumbnail` | string | The public URL of a thumbnail shown while the file loads. |
| `caption` | string | The media caption. If you omit it, `body` is used. |
| `height` | string | The media height in a rich card: `SHORT`, `MEDIUM`, or `TALL`. Defaults to `MEDIUM`. Applies only when the message is delivered as a rich card. |
| `forceRefresh` | boolean | Forces the RCS platform to download the file again, even if it has a cached copy. |

How the message is delivered depends on the text:

- **Without `caption` or `body`**, the file is sent on its own.
- **With `caption` or `body`**, the message is delivered as a rich card, and the text becomes its description.

Use at most one media field per message.

```json Standalone image
{
  "rcs": {
    "sender": "muj_rcs_agent",
    "image": "https://example.com/boarding-pass.png"
  }
}
```

```json Image as a rich card with the description from body
{
  "rcs": {
    "sender": "muj_rcs_agent",
    "body": "Your boarding pass",
    "image": "https://example.com/boarding-pass.png"
  }
}
```

```json Video with a thumbnail and a custom caption
{
  "rcs": {
    "sender": "muj_rcs_agent",
    "video": {
      "url": "https://example.com/how-to.mp4",
      "thumbnail": "https://example.com/how-to-thumb.jpg",
      "caption": "Assemble your table in 5 minutes",
      "height": "TALL"
    }
  }
}
```

## Buttons (`buttons`)

The `buttons` array adds **reply suggestions** (chips) below the message. Each button has a `type` — either `reply` (a quick reply) or `url` (opens a link).

| Button field | Applies to | Description |
| --- | --- | --- |
| `type` | both | `reply` or `url`. |
| `text` | both | The button label. |
| `postback` | both | The value returned in the incoming webhook when the recipient taps the button (`postbackData`). |
| `url` | `url` | The target URL. Required for `url` buttons. |
| `description` | `url` | A description of the link being opened. |
| `webview` | `url` | Opens the URL in an in-app webview instead of the browser. Set the size with `FULL`, `HALF`, or `TALL` (`webviewViewMode`). |

```json
{
  "rcs": {
    "sender": "muj_rcs_agent",
    "body": "Jak vám můžeme pomoci?",
    "buttons": [
      { "type": "reply", "text": "Stav objednávky", "postback": "ORDER_STATUS" },
      { "type": "url", "text": "Otevřít e-shop", "postback": "OPEN_SHOP", "url": "https://example.com" }
    ]
  }
}
```

## Standalone rich card (`card`)

The `card` field sends a single card with an image/video, a title, a description, and optional buttons.

| Field | Type | Description |
| --- | --- | --- |
| `title` | string | The card title. |
| `description` | string | The card description. |
| `file` | string | The media URL (image/video). |
| `thumbnail` | string | The thumbnail URL. |
| `height` | string | The card's media height: `SHORT`, `MEDIUM`, or `TALL`. Defaults to `MEDIUM`. |
| `buttons` | array | The card buttons (same shape as above). |

```json
{
  "rcs": {
    "sender": "muj_rcs_agent",
    "card": {
      "title": "Letní sleva",
      "description": "Sleva 20 % na celý sortiment do konce měsíce.",
      "file": "https://example.com/promo.jpg",
      "thumbnail": "https://example.com/promo-thumb.jpg",
      "buttons": [
        { "type": "url", "text": "Nakoupit", "postback": "SHOP", "url": "https://example.com/sale" }
      ]
    }
  }
}
```

## Carousel (`carousel`)

The `carousel` field sends a horizontally scrollable row of **2 to 10** cards. Each card has the same fields as a standalone rich card:

| Field | Type | Description |
| --- | --- | --- |
| `title` | string | The card title. |
| `description` | string | The card description. |
| `file` | string | The media URL. |
| `thumbnail` | string | The thumbnail URL. |
| `height` | string | The card's media height: `SHORT`, `MEDIUM`, or `TALL`. Defaults to `MEDIUM`. |
| `buttons` | array | The card buttons. |

```json
{
  "rcs": {
    "sender": "muj_rcs_agent",
    "carousel": [
      {
        "title": "Produkt A",
        "description": "Skladem",
        "file": "https://example.com/a.jpg",
        "thumbnail": "https://example.com/a-thumb.jpg",
        "buttons": [{ "type": "url", "text": "Detail", "postback": "A", "url": "https://example.com/a" }]
      },
      {
        "title": "Produkt B",
        "description": "Novinka",
        "file": "https://example.com/b.jpg",
        "thumbnail": "https://example.com/b-thumb.jpg"
      }
    ]
  }
}
```

## Raw passthrough (`raw`)

For content this interface does not cover, pass a `raw` object — the `suggestions` key for custom suggestions or `richCard` for a custom card is sent to the RCS API unchanged.

```json
{
  "rcs": {
    "sender": "muj_rcs_agent",
    "body": "…",
    "raw": { "suggestions": [ { "reply": { "text": "Ano", "postbackData": "YES" } } ] }
  }
}
```
